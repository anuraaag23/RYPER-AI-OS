## Documented Known Limitations

1. **Local Qwen3-8B Hybrid GPU/CPU Prefill Latency:**
   On systems with limited free GPU VRAM (~600–700 MiB available due to display servers and other GPU clients), `llama-server` executes large initial tool-schema prompt prefills (over 7,500 tokens) via hybrid CPU offload, requiring 90–150 seconds for the initial turn before KV prefix caching takes effect.
2. **CapabilityBroker Headless Interaction:**
   In headless or automated testing environments lacking interactive confirmation dialog responses, Mutating Windows tools fail-closed as designed, prompting the user for capability grants.
3. **Multilingual Voice Wake-Word:**
   Push-to-Talk and UI activation remain the certified activation mechanisms; wake-word recognition on Hindi/Hinglish relies on speech recognition post-activation rather than always-on neural wake-word models.
4. **Hinglish Language Setting:**
   Hinglish speech recognition performs optimally when `voiceLanguage` is configured to `hi` or `auto`.
