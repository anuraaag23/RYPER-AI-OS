## 2. Milestone Deliverables & Implementation Details

### P3-1 — First-Run Onboarding Modal
- **Component**: [`OnboardingModal.tsx`](file:///C:/Users/anura/Downloads/@@@RYPER%20AI%20%28Alexa%29/ryper-os/platform/desktop-app/src/components/OnboardingModal.tsx)
- **Design & Flow**:
  - **Step 1**: On-Device Intelligence & Privacy — explains local model execution, offline capabilities, and zero data telemetry.
  - **Step 2**: Windows Control with Consent — explains safe desktop control, window management, and strict user confirmation gates.
  - **Step 3**: Voice & Text Interaction — introduces the push-to-talk shortcut (`Ctrl + Shift + Space`) and natural multilingual understanding (English, Hindi, Hinglish).
- **Interactions**:
  - Step navigation with Back / Next buttons and accessible step dots (`aria-label="Step X of 3"`).
  - Primary button autofocus on step change.
  - "Skip" button dismisses immediately from any step.
  - Escape key listener closes the modal.
- **Persistence**:
  - Dual-layer persistence: `localStorage.getItem("ryper_onboarding_completed")` for instant zero-flicker client-side resolution + `settings.hasCompletedOnboarding` in `settings.json` via IPC.
  - Verified across process relaunches: does NOT recur once completed or dismissed.

### P3-2 — Local AI / Model Readiness UX
- **Type Contract**: [`LocalAIReadinessState`](file:///C:/Users/anura/Downloads/@@@RYPER%20AI%20%28Alexa%29/ryper-os/platform/desktop-app/electron/ipc-contract.ts) (`"ready" | "starting" | "missing" | "failed"`).
- **IPC Handler**: `IPC_CHANNELS.getAIStatus` truthfully reports model engine status without leaking file paths, exit codes, or port numbers.
- **UI Exposure**:
  - Header AI status indicator shows readiness badge.
  - Popover displays clear readiness state (`Ready`, `Starting`, `Missing`, `Offline`).
  - Actionable paths provided when missing or failed ("Set up Local AI" / "Restart Local AI").

### P3-3 — Crash & Recovery UX
- **Component**: [`ErrorBoundary.tsx`](file:///C:/Users/anura/Downloads/@@@RYPER%20AI%20%28Alexa%29/ryper-os/platform/desktop-app/src/components/ErrorBoundary.tsx)
  - Catches unexpected React render-tree crashes.
  - Renders a clean glassmorphism recovery card with reassuring copy ("Your data, conversations, and settings remain safe").
  - Provides a single prominent action: "Reload Application".
  - Strictly conceals raw stack traces, local paths, or internal exceptions from end users.
- **Main Process Recovery**:
  - `IPC_CHANNELS.restartLocalAI`: performs safe health check and status broadcast without arbitrary process execution.
  - Error banner in `ChatPanel.tsx` offers safe retry and restart for offline or disconnected errors.

### P3-4 — Diagnostics & Support UX
- **Component**: [`SettingsApp.tsx`](file:///C:/Users/anura/Downloads/@@@RYPER%20AI%20%28Alexa%29/ryper-os/platform/desktop-app/src/SettingsApp.tsx)
- **Structured Health Cards**:
  1. **Core Gateway**: IPC Orchestrator & State Engine (`Healthy` / `Degraded` / `Unhealthy`).
  2. **Local AI Runtime**: Model engine readiness, model label, friendly detail.
  3. **Platform & OS**: Windows x64 platform and OS version (`Supported`).
  4. **Memory Subsystem**: Local SQLite & Vector store (`Active`).
  5. **Capability Broker**: Guarded mode with active capability count (`Guarded`).
- **Live Actions**:
  - **"Run Health Check"**: Live refresh of health status and AI engine readiness without page reload.
  - **"Copy Diagnostics"**: Exports strictly sanitized JSON (`formatSanitizedDiagnostics`).
    - Windows user paths (`C:\Users\...`) redacted to `[USER_PATH]`.
    - Registry keys (`HKLM\...`, `HKCU\...`) redacted to `[REGISTRY_KEY]`.
    - Sensitive tokens, credentials, and passwords redacted to `[REDACTED]`.
  - **"Open Logs Folder"**: Safe main process handler invoking Electron's `shell.openPath(app.getPath("logs"))` with error handling.
