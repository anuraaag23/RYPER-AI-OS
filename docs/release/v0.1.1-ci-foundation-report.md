## CI Design

The CI pipeline is structured to provide an automated, reproducible validation safety net without introducing deployment, publishing, or release risks:

- **Workflow Path:** `.github/workflows/ci.yml`
- **Triggers:**
  - Pushes targeting `main`
  - Pull requests targeting `main`
  - *Zero execution on release publication or tag creation*
- **Concurrency Control:** Cancels superseded runs for the same branch or PR to conserve CI runner minutes:
  ```yaml
  concurrency:
    group: ${{ github.workflow }}-${{ github.ref }}
    cancel-in-progress: true
  ```
- **Deterministic Installs:** Uses `npm ci` against the repository's tracked `package-lock.json`.

## Jobs Created

The workflow creates two distinct, transparent validation jobs:

1. **`test-linux` (Linux Ubuntu Build & Test):**
   - **Runner:** `ubuntu-latest`
   - **Purpose:** Verifies platform-independent packages (`core/*`, `plugins/*`, `ui/*`, `infra/*`, `platform/web`) and ensures Linux development compatibility.
   - **Timeout:** 15 minutes.

2. **`test-windows` (Windows Build & Test):**
   - **Runner:** `windows-latest`
   - **Purpose:** Verifies Windows desktop integration (`@ryper/desktop-app`, `@ryper/windows-agent`, PowerShell interop stubs) in a native Windows environment.
   - **Timeout:** 15 minutes.

## Commands Executed

1. `npm ci`: Clean, deterministic dependency installation from lockfile.
2. `npm run build`: Type-checks and compiles all workspace packages via project references (`tsc --build tsconfig.json`).
3. `npm run build --workspace=@ryper/desktop-app`: Compiles Vite UI production bundle and esbuild preload script.
4. `npm test`: Executes all 239 Vitest suites (1,648 passed / 13 skipped / 0 failed).
