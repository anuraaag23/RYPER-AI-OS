## 1. Release Scope & Platform Target

RYPER AI OS v0.1.0 is an autonomous, offline-first AI operating system desktop application built for Windows 11 (64-bit). It integrates:
- Native Windows Subsystem Automation (Filesystem, Applications, Windows, Processes, Audio, Notifications, Registry, Services, Tasks, Network, Power)
- Duplex Real-Time Voice Processing (Microphone Capture, Energy VAD, Local Whisper STT, Intent Routing, Local Piper TTS, Audio Playback)
- Multilingual Support for English, Hindi (Devanagari), and conversational Hinglish
- 100% Offline Inference via local Qwen3-8B GGUF (llama-server)
- Least-Privilege Security Perimeter enforced by CapabilityBroker and DestructiveActionGate

## 6. Documented Operational Limitations

1. **Local LLM Hybrid Execution Latency**:
   On 6 GB Laptop GPUs (RTX 4050), Qwen3-8B runs with ~35 layers on GPU and remaining layers across 10 CPU threads. Complex tool-calling turns take ~65–92 seconds.
2. **Heuristic Wake-Word Activation**:
   Wake-word detection uses a 3-pulse amplitude envelope matching heuristic (`EnergyWakeWordProvider`). Push-to-Talk (`Ctrl+Space`) is the certified trigger for production reliability.
3. **Whisper Language Selection for Hinglish**:
   Transliterated Hinglish commands on `ggml-base.bin` require setting `voiceLanguage: "hi"` for reliable phonetic accuracy. Short audio under `auto` mode is susceptible to misdetection.
4. **Human Auditory Perception**:
   Output pipeline execution and speaker sink dispatch are physically certified; subjective human auditory perception is reserved for the physical user.
5. **Network and Service Mutation Elevation**:
   Modifications to static IP, DNS servers, network adapter states, and background Windows services require Windows Administrator elevation (UAC prompt).

## 7. Explicitly Unsupported / Uncertified Areas

- **Neural Acoustic Keyword Spotting**: Neural wake-word (e.g. Porcupine / openWakeWord) is not certified in v0.1.0. Push-to-Talk is certified.
- **macOS / Linux Deployments**: v0.1.0 packaging is strictly targeted to Windows 11 x64.
- **Full GPU Offload on <=6 GB VRAM**: Full 99-layer CUDA offload of Qwen3-8B requires >=10 GB VRAM.
- **Silent Cloud Substitution**: Cloud LLMs are never silently contacted; only local models run unless explicit vendor API keys are set.
